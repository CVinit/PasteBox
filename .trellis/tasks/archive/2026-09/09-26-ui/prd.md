# 在线剪贴板与文件中转站 UI 调研

## Goal

搜索并整理全球在线剪贴板、文本分享和文件中转产品，给 PasteBox 后续界面设计提供可直接浏览的参考。

## Requirements

* 收集约 10–15 个有代表性的产品官网或主要使用页面，优先覆盖在线剪贴板、临时文本分享、文件传输/中转等类别。
* 为每个产品记录可访问链接、产品类型、核心交互路径，以及值得参考的页面布局和控件。
* 仅将本轮实际打开或可由可信来源核验的信息作为已核实观察；区分官网链接与具体页面的可访问性。
* 以中文 Markdown 文档交付到 `docs/online-clipboard-file-transfer-ui-research.zh-CN.md`。
* 总结跨产品共性和对 PasteBox UI 的可借鉴方向，不改动应用代码和其他既有文档。

## Acceptance Criteria

* [ ] 中文调研文档包含 10–15 个产品和可点击链接。
* [ ] 产品按类别整理，并覆盖首页/创建入口、分享流程、时效或隐私等可观察设计点。
* [ ] 结论有来源支撑，页面无法访问或功能未核实时明确标注。
* [ ] 只新增目标调研文档及必要的 Trellis 任务记录。

## Definition of Done

* 文档内容和链接完成核对，检查 Markdown 结构和链接文本。
* 在最终报告中说明验证方式、限制和后续使用建议。

## Out of Scope

* 不实现或修改 PasteBox 功能和 UI。
* 不进行完整市场规模、商业模式或安全审计分析。
* 不注册账号、不上传真实文件或创建公开分享内容。

## Technical Notes

* 搜索通过本机 `smart-search` CLI；doctor 显示最低搜索能力配置可用，Exa、Tavily、主搜索和页面抓取能力已配置。
* 调研以产品公开官网/产品页为主，具体交互仅在页面实际可访问时记录。
