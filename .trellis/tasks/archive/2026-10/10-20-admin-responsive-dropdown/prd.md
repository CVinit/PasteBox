# 后台非全屏布局与网页内下拉选择

## Goal

后台在浏览器非全屏和窄内容区内完整显示，所有后台选择框使用网页内展开的下拉列表。

## Confirmed Requirements

用户已确认：按实际可用宽度收起后台导航、调整表单列数，长内容换行；后台全部选择框（含日志等级、单位、用户套餐和应用配置）统一使用网页内下拉，支持键盘操作、点击外部关闭。

## Acceptance Criteria

- [x] 320/375px 手机及 981/1024/1100/1200/1440px 窗口下，12 个后台页面无页面、面板或主网格横向溢出，工作区侧栏展开/收起均可使用。
- [x] 后台导航根据内容可用宽度切换，表单、长文本和按钮保持可读可操作。
- [x] 后台不再使用原生选择弹出框；下拉选项支持已选状态、滚动、焦点、键盘和点外关闭，受窄窗口及滚动约束。
- [x] 日志等级、单位换算、应用配置切换和用户套餐更新仍正确工作。
- [x] 四语言可用，相关前端测试、类型检查、构建及静态资源同步通过，真实浏览器验证完成。

## Technical Notes

- 在主会话执行 Trellis inline 流程，不派子代理。
- 复用现有 React / lucide-react，不引入组件库或修改接口。
- 原有未提交文件不属于本任务，不覆盖或纳入提交。
- 缺失的图 1 以实际窗口尺寸复现；图 2 指向服务配置中的日志等级。

## Out of Scope

生产部署、远程推送、普通工作区的筛选/语言等选择框、后端语义变化。
