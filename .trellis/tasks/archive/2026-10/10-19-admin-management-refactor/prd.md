# 后台管理重构

## Goal

补齐后台用户、文件管理及套餐展示入口，改善导航和审计、队列的可读性。

## Confirmed Requirements

用户已于 2026-10-19 确认以下方案：

- 桌面左侧导航、右侧内容；手机可折叠菜单。概览保留统计、运行状态及待办。
- 用户管理独立页面，搜索、分页、查看套餐与到期时间、冻结/解冻和调整套餐。
- 文件管理独立页面，搜索、分页、归属用户、大小、扫描状态、冻结/解冻、重扫、内容下架及分享撤销。
- 套餐页顶部增加全站套餐展示开关，保留价格可见/购买开关。全站关闭时同步隐藏公开页面及工作区套餐入口、套餐区，但不修改已有权益或套餐配置。
- 审计独立紧凑表格，时间/操作/操作人/对象，操作名称本地化、长标识可查完整内容；队列及清理分开布局。
- 复用接口、权限、运行配置持久化和国际化；不引入组件库。

## Acceptance Criteria

- [x] 后台导航在桌面和手机可用，概览不再承载截断的管理列表。
- [x] 用户搜索和分页可访问所有匹配记录，冻结和套餐调整正确保存并显示反馈。
- [x] 文件搜索和分页可访问所有匹配记录，现有管理动作正确执行。
- [x] 全站套餐展示设置可保存、重启后保留；旧配置默认显示；前台各入口与设置一致。
- [x] 审计日志长操作名、用户 ID 和空状态不造成单字竖排、异常高度或页面溢出。
- [x] 相关 Go 测试、前端测试、类型检查、构建通过，嵌入静态文件同步。
- [x] 浏览器验证桌面、375px 手机及管理动作；明确模拟接口与真实服务验证边界。

## Technical Notes

- 页面：web/src/App.tsx；API：web/src/api.ts；样式：web/src/styles.css。
- 后端：internal/app/runtime_control.go、internal/app/admin.go、internal/httpserver/server.go。
- 现有用户/附件接口已有 limit/offset；用户搜索需补齐服务与持久化查询。
- 审计问题：外层 auto-fit 卡片与内层 minmax(0,1fr) auto 网格组合挤压标题。
- 当前工作区有用户既存改动，限本任务文件操作，禁止覆盖无关改动。

## Out of Scope

- 生产部署、推送、权限体系重做、删除用户、支付或已有套餐权益语义变更。

## Verification

2026-10-20 已完成实现与自动验收，详情见 verification.md。桌面、375px、320px 的 12 个后台页面均无页面/面板/主内容网格横向溢出；四语言已检查。视觉效果供用户通过截图与本地预览继续确认，自动检查不代表用户已认可视觉风格。
