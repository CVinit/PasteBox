# ADR 004：可配置接收者的阅后即焚

状态：已确认；用户在 to-tickets 工单拆分确认中批准最终销毁条件。

## 已确认

- 用户将固定单接收者修订为分享时可设置一位或多位接收者，每位一次领取，其他已提出规则同意。
- 默认关闭，独立开关，明确提示破坏性后果；仅打开链接不领取。
- 文本主动查看，文件主动领取；文件会话最长 30 分钟且不超过原有效期，支持逐个下载和失败重试，完成领取或到期结束。
- 销毁这份传输的内容与附件，物理文件后台清理，不影响已保存的接收端副本。
- 用户选择 A：设置 1 或 N 个领取名额，每次领取占一个名额；同一领取会话内可下载多个文件及重试，不强制引入接收者注册或邮箱验证，原有登录限制仍生效。
- 名额不是自然人身份，不承诺不同名额一定由不同的人领取。

## 多人修订带来的待决问题

- 原单人方案中首次读取即删除、首次领取排斥其他人的行为，改为每个名额只领取一次。
- 已确认：全部名额已领取且所有会话结束后销毁；未领满则保留至分享有效期，到期销毁。落地工单为 GitHub Issue #11。
- 并发占位、重复请求幂等、名额耗尽但已有会话仍有效的行为须在实施前形成可测试契约。
