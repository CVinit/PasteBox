# ADR 001：文件中转优先

状态：产品方向与入口结构已确认，传输和销毁细节待确认。

## 背景

用户选定研究文档第六节七项全部落地，并根据第八节的流量对比，要求 UI 与文案转向文件中转。

## 决策

- 以文件发送、接收和中转作为主叙事，保留文本与图片能力。
- 优先复用现有风格和服务能力；涉及取件码、同步与销毁时补齐真实行为，而非仅新增外观控件。
- 调研流量数据只支持方向判断，不当作精确关键词搜索量或获客保证。
- 用户确认首页采用“发文件 / 取文件”，默认发送文件，图片和文本为可切换模式；首屏直接操作。
- 接收支持链接或取件码，成功页突出凭据和有效期；登录工作区突出发送与传输记录并保留内容管理。

## 影响

- 不止调整首页文案，还需梳理游客、登录、分享成功与接收页面的一致性。
- “取件码”“同步”“阅后即焚”需要独立的行为定义和测试。
- 文件组织方式和销毁范围将在后续访谈中确认。
