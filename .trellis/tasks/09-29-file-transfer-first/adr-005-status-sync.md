# ADR 005：文件中转状态同步

状态：用户已确认范围，具体技术实现待代码链路核验。

## 决策

- 同账号多设备同步传输记录、领取次数、过期与销毁状态。
- 发送成功页自动更新领取状态，接收页自动更新可领取、已领完、已失效状态。
- 显示真实连接状态：已连接、重连中、连接中断，重连后补齐最新状态。
- 文本保存后同步，不做逐字协同编辑，不自动读取系统剪贴板。
- 游客只查看凭据授权范围内的传输状态，不提供匿名共享房间。

## 约束

- 实施前核验现有事件机制与部署链路，再选择最小增量方案，不先指定协议或新增依赖。
- 订阅状态不应领取名额或触发阅后即焚。
- 不跨用户或跨凭据泄露内容和事件；撤销、过期与销毁后更新访问权限。
- 重连获取权威最新状态；刷新时保护尚未保存的编辑。
