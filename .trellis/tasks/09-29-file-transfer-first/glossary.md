# 术语表（讨论稿）

| 术语 | 定义与边界 |
| --- | --- |
| 文件中转 | 发送方上传、接收方通过分享凭据访问文件的主场景；不默认承诺永久网盘。 |
| 一份传输 | 一次发送的多个文件，共用分享链接、取件码和有效期；全部上传成功才发布分享，登录记录按此归组。 |
| 发送区 | 创建待分享内容的入口；默认文件上传，支持切换图片与文本，内联展示时效和隐私设置。 |
| 取文件 | 接收已有分享，不等于向他人征集文件。 |
| 分享链接 | 指向分享内容的地址，沿用现有分享概念。 |
| 取件码 | 6 位数字与大写字母组合，排除易混淆字符，输入不区分大小写；与链接共用权限、有效期和撤销状态，受防猜码限流保护。 |
| 内容保留期 | 原始内容可用的期限，与单个分享链接的有效期不同。 |
| 分享有效期 | 特定分享凭据可用的期限，不应超过内容保留期。 |
| 实时同步 | 同账号跨设备更新传输记录、领取次数及过期/销毁状态，文本保存后同步；游客仅在凭据授权范围内更新状态，不含逐字协同编辑。 |
| 连接状态 | 实际通信链路状态，不将浏览器联网直接等同于内容已同步。 |
| 阅后即焚 | 独立可选的销毁策略，支持一位或多位接收者、每位一次领取；销毁范围为传输内容和附件，后台物理清理。多人最终触发条件待确认。 |
| 接收者 / 领取名额 | 用户已选择匿名名额模式：设置 1 或 N 个名额，每次领取占一个；不核验独立自然人身份，界面优先用“可领取次数”避免误导。 |
| 领取会话 | 文件接收者主动领取后的访问窗口，最长 30 分钟且不超过原有效期；支持逐个下载与失败重试，完成领取或到期结束。 |
| 次数限制 | 限制访问或下载次数，本身不代表删除原始内容。 |
| 自然搜索流量 | 文档中站点从搜索引擎获得流量的估算，不等于关键词搜索次数或全部访问量。 |
