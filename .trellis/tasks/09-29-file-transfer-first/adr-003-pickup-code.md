# ADR 003：6 位取件码

状态：已由用户确认，长度按用户要求从建议的 8 位调整为 6 位。

## 决策

- 数字与大写字母组合，排除易混淆字符，输入不区分大小写。
- 与链接共用内容、权限、有效期和撤销状态，不构成绕开密码或登录限制的入口。
- 游客与登录用户均支持，沿用各自配额与保留期限。
- 输入错误统一提示，连续尝试过多时限流。
- 老链接继续有效，不强制给历史分享补码。

## 实现约束（待设计核验）

- 生成使用安全随机源，处理并发分配冲突，保证有效码唯一。
- 6 位码空间有限，必须核验猜码限流、多实例一致性以及错误响应的信息泄露边界。
- 具体字符集、限流阈值和过期码再分配规则在技术设计中明确，不改变已确认的 6 位交互。
