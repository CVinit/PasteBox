# ADR 002：按发送批次组织多文件

状态：已由用户确认。

## 决策

- 一次选择或拖入多个文件作为一份传输，共用链接、取件码和有效期。
- 接收页展示清单并逐个下载，登录传输记录按发送批次归组。
- 展示逐文件进度；失败只重试失败项，全部成功后才生成分享。
- 本轮不做打包下载、文件夹上传、断点续传。

## 影响及后续设计约束

- 需要明确上传中与已发布的边界，避免接收方拿到不完整文件清单。
- 实施前核验重试幂等、取消或放弃上传后的清理与配额恢复。
- 文件阅后即焚规则需考虑同一批次内逐个下载，不能下载第一个文件就导致其余文件丢失。
- 此决策是产品行为约束，不预设新增数据表或重写现有存储模型。
